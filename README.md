# MY ENGLISH — Метод Холмата

Персональный тренажёр английского языка для жизни и работы.

## Учебная последовательность

1. Карточки слов с двумя направлениями перевода.
2. Письменная проверка словаря в обоих направлениях.
3. Практическая грамматика с объяснениями на русском.
4. Ролевые разговоры и аудирование с помощью Gemini.
5. Повторение слабых мест и сохранение прогресса.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Секреты

Ключ Gemini будет храниться в настройках Secrets среды развёртывания, а не в Git. Не добавляйте API-ключи в исходный код или файлы репозитория.

## Текущий этап

Начальная версия интерфейса: базовый словарь A1, карточки, письменная проверка и локальная база SQLite. Перед постоянным использованием в облаке нужно подключить надёжное постоянное хранилище прогресса и интеграцию Gemini.
